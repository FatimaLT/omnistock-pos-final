OmniStock & POS

Manual técnico resumido · versión vigente al 25 de noviembre de 2026

La aplicación actual es PHP/MySQL con JavaScript nativo; no es una aplicación React/Vite. Las operaciones de tarjeta y transferencia son simulaciones.

Stack

CapaTecnología
InterfazPHP, HTML semántico, CSS y JavaScript ES6+
BackendPHP 8+, PDO y endpoints JSON
PersistenciaMySQL/MariaDB con transacciones InnoDB
MapaLeaflet y mosaicos de OpenStreetMap

Arquitectura

El proyecto separa configuración y datos en config/, endpoints en api/, administración en admin/, estilos/scripts en assets/ y componentes PHP en components/ organizados en atoms, molecules, organisms, templates y pages.

El flujo de venta valida sesión y CSRF, vuelve a consultar precios y existencias del servidor, y guarda la venta/detalles y el descuento de stock dentro de una transacción. El ticket se consulta luego mediante una ruta autorizada.

Instalación local en Windows

  1. Instala XAMPP con PHP 8+, MySQL/MariaDB y pdo_mysql.
  2. Copia .env.example a .env, configura credenciales locales y crea una base dedicada en MySQL.
  3. Desde la carpeta del proyecto, ejecuta php -S 127.0.0.1:8765 -t . o utiliza Apache en XAMPP.
  4. Abre http://127.0.0.1:8765/login.php. El servidor PHP integrado es solo para desarrollo y no aplica `.htaccess`.

Validaciones

En PowerShell ejecuta .\scripts\validate.ps1 para revisar sintaxis PHP/JavaScript y las pruebas unitarias básicas.

Límites y despliegue

Antes de publicar, configura HTTPS, variables seguras, base aislada, permisos mínimos, reglas de archivos privados y respaldos probados. Valida en el hosting las rutas amigables y el mapa.

La transferencia demo no verifica depósitos; si termina su cuenta regresiva registra una venta y descuenta stock. El PIN de tarjeta no se procesa con un banco, las tasas de divisa son demostrativas y el resumen de sucursales se basa en reglas locales.
